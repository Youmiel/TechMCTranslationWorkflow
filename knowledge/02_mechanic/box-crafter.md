# Box Crafter（潜影盒合成机）

## 要点
- 存储系统中**自动合成/染色潜影盒**的装置：依靠合成器（crafter）自动合成空潜影盒的装置，可能附带染色等额外功能。
- 常作为存储系统的一部分用于**自动补盒**。
- 命名惯例：装置名常带「Ngt（游戏刻）」前缀（如 16 gametick box crafter），**N 指运行周期**（每 N 刻完成一个合成循环），而非单次耗时。
- ⚠️ 关键理解：带 Ngt 前缀时，**Ngt 是运行周期**（合成循环间隔），而非合成耗时、熔炉刻度或其它量。

## 翻译注意事项
- 标准译名：潜影盒合成机（`box crafter`，2026-08-13 用户确认，见 `knowledge/01_terminology/_uncategorized.csv`）。
- 带周期前缀时译「**以 Ngt 为周期的**」：如「以 16gt 为周期的潜影盒合成机」，**不可**直译成「16 游戏刻潜影盒合成机」（Ngt 是周期不是耗时）。
