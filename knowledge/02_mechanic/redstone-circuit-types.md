# Redstone Circuit Types（红石电路种类 / 「x 电」缩写体系）

## 要点

中文红石社区用「x 电」简称红石电路的各个基本种类（wiki `红石电路#基本种类`）：

| 全称 | 简称 / 别名 | 简述 |
|------|-------------|------|
| 生存实用电路 | **生电**、生存红石电路 | 主要服务生存模式的红石电路，追求高效率、方便快捷、卡顿低、稳定性强 |
| 红石数字电路 | **数电**、红数 | 通过红石元件与逻辑机制（或 / 与 / 非）实现逻辑运算、算术运算、自动控制 |
| 红石模拟电路 | **模电**、红模 | 与数电类似，但基于红石信号强度运算，主要借助比较器完成 |
| 红石机械电路 | **械电** | 利用方块（活塞、黏性活塞、发射器）与实体（矿车卡位、矿车挤压、拴绳等）的游戏特性实现目标 |
| （创造红石电路） | **创电** | 见下方说明——**带讽刺/自嘲色彩，非独立分支** |

- 另有「**赤石科技**」（沙雕红石 / 无用红石，Reekstone）——与传统红石机器理念背道而驰、纯娱乐，不属「x 电」序列
- **「创电」多用于讽刺、自嘲**：指设计脱离实际、不考虑实装成本与可行性（如生存模式下无法实现、需无蓝图直接修建）。**不宜当作独立技术分支考量**——创造模式本就是大部分电路设计的基础模式，实装成本与所在模式无关；现实中也没人直接在生存模式里研究复杂技术、或凭空修建复杂装置
- **绿萌 ≠ 械电**：`Slimestone` 是主黏液块 / 蜂蜜块的技术，定义「主黏液块的红石技术，包括各种机器中的黏液块部分和飞行器；狭义上仅指飞行器技术」。它**属于械电**——是械电中**专玩飞行器**（飞行器、活塞虫等可移动机械）的一支；而传统械电的主战场是固定式活塞机械（最快 / 最小活塞门、树场时序布线等）
- **储电**（`storage tech`）是社区对「存储技术」分支的称法，不在 wiki 的分类表内，但同属「x 电」命名习惯

## 翻译注意事项

- 英文字幕的对应关系（均按**语义**对应，不按自造英文名硬套）：
  - 生存向、生存模式实用电路语境 → **生电**（或全称「生存实用电路」）
  - 逻辑运算、算术运算、自动控制语境 → **数电**
  - 比较器、信号强度运算语境 → **模电**
  - 活塞等机械方块 + 实体特性的装置语境 → **械电**
  - `storage tech` → **储电**；`Slimestone` / 飞行器语境 → **绿萌**
- **「创电」慎用**：一般是调侃/贬义（设计不顾实装、脱离实际），**不是中性分类词**——不要一看到"创造模式设计"就译「创电」；英文字幕里通常根本没有对应词，只是描述"在创造模式里设计的"而已
- 「x 电」是**中文社区自造的简称**，无对应英文术语——**勿反向硬造 / 勿套用似是而非的英文名**；英文字幕只按上述语义对应
- 绿萌与械电**不可互相替代**：绿萌是械电的下位分支（专玩飞行器），写「械电」时不等于「绿萌」，反之亦然
