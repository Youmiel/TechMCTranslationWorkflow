# 字幕数字体例（Number Style）

## 要点

字幕中文的数字书写口径（用户裁定，全项目通用）：

| 类别 | 口径 | 示例 |
|------|------|------|
| **数值 + 数量词** | 阿拉伯数字 | `9 个格子`、`4 个游戏刻`、`6 个面`、`5 个槽位`、`2 部分`、`3 个主要功能` |
| **分数** | 阿拉伯分数式 | `1/3`、`1/9`、`1/2`、`8/9`（不写「三分之一」） |
| **信号强度档位** | 阿拉伯 + 「档」 | `2 档信号强度`、`3 档`（不写「二档/三档」） |
| **千分位** | **不加逗号** | `72000`、`18000`、`9000` |
| **序数词** | 保留中文 | `第一格`、`第二个槽位`、`第三个` |
| **虚指 / 单位量** | 保留中文 | `一件物品`、`一部分`、`一种`、`一个方块`、`一次性`、`一个一个来` |

## 翻译注意事项

- **判定分界 = 是否计数**：能对应具体数量的 → 阿拉伯；表顺序（序数）或表"某个/某个量级"（虚指）的 → 中文。
  - 对：`每 4 个游戏刻发一次`、`如果有 3 个格子放了物品`
  - 对：`拿第一件物品`、`随机挑一个来发射`、`漏斗一次也只能处理一件`
- **同一概念的单位词须前后统一**：同一 signal strength 概念不可一处写「3 格信号强度」、另一处写「2 档信号强度」——「格」与「档」需择一。
- **易漏点：分数与数值常相邻出现**（`概率就是 1/3；一直推广到 9 个格子，就是 1/9。`），只改一半会留下体例混用，需成对处理。
- **口语 `X in Y` 的两义**：概率语境 `1 in 3` → 分数式 `1/3`；槽位数语境 `9 slots where it's 1 in 9` → `9 个格子，就是 1/9`。
