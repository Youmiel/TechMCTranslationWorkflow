# Credits（致谢 / 引用）

## 要点
- credits 在视频语境存在多义：
  - **致谢/名单**：视频末尾或简介中的致谢、制作人员名单（credit/credits）。
  - **引用来源**：简介中致谢/引用所指向的**对象**——「credits video」指被引用、被给予荣誉的那个视频。
- 「credits video」中的 credits 是修饰性用法，指向被致谢/被引用的视频本身。

## 翻译注意事项
- 「credits video」（如简介中列出的引用来源）→ 译「（简介）引用的视频」，而非「致谢视频」。
- 依据：语境推断 + 用户确认；此义长期易翻不准，遇到时注意识别。
