# Target（标靶方块 / 目标）

## 要点
- target 在 Minecraft 语境存在多义，翻译前必须按上下文判定：
  - **标靶方块**（target block）：1.16 加入的红石元件，被投射物击中时输出与命中位置相关的红石信号，常用于射击靶场、计分板等装置。
  - **目标**（通用义）：实体（如怪物）当前选定的攻击/追踪对象（如 mob's target）。
- 判定线索：投射物、红石信号、计分板、射击等语境 → 标靶方块；攻击、仇恨、追踪、寻路等语境 → 目标。

## 翻译注意事项
- 标靶方块义 → 译「标靶」（需强调方块全称时可译「标靶方块」）；目标义 → 译「目标」。
- 禁止一律直译，须按语境二选一。
